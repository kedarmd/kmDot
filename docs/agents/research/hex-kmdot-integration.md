# Hex dictation on kmDot

Hyprland forwards **Alt+Space** to the registered `anomaly.hex:dictation` action. Hold the shortcut while speaking and release it to transcribe when Hex is in Hold mode. **Super+H** runs `hex window show history`.

Hex uses its native recording indicator. Its settings control indicator placement, microphone selection, models, history retention, and launch at login.

Run `hex status` to check the listener, model, and permissions. While Hex is running, `hyprctl globalshortcuts` lists the registered dictation action.
